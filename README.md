Проект содержит автотесты для API яндекс прилавка
Для запусков тестов установите зависимости и запустите pytest ИЛИ удалите символ # с тестов в VSC (в самом конце create_kit_name_kit_test.py)
Я старался коммть весь процесс чтобы самому не сбиваться с мысли и логики.

Из 11 тестов, 7 тестов прошли успешно, 4 теста провалились. 
Провалились:
    3 тест (пустая строка), код 201 а должен быть код 400.
    4 тест (слишком длинное название 512 символов) код 201 а должен быть код 400.
    10 тест (нет поля "название") код 500 а должен быть код 400.
    11 тест (вместо поле "строка" стоит "число") код 201 а должен быть код 400.


Содержимое проекта:
    configuration.py - адреса сервера и пути к API
    data.py - заголовки и шаблоны
    sender_stand_request.py - функции для отправки запросов
    create_kit_name_kit_test.py - сами тесты находятся здесь
    .gitignore - файлы которые не нужно отслеживать
